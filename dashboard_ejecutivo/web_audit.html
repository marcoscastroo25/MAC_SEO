¿Cómo funciona esta auditoría?

El Agente de Optimización de Crecimiento simula de forma autónoma una visita real a tu sitio web utilizando un navegador controlado por código (Puppeteer). Durante la simulación, el agente realiza tres análisis principales:

  • Rendimiento Técnico: Mide los Core Web Vitals (velocidad de carga visual, interactividad y estabilidad).
  • Estructura SEO On-Page: Inspecciona etiquetas HTML (títulos, descripciones, jerarquía H1/H2, imágenes sin texto alternativo) esenciales para posicionar en Google.
  • Experiencia de Usuario (UX): Analiza contrastes, alineaciones y genera un mapa de calor predictivo de fricción visual.
