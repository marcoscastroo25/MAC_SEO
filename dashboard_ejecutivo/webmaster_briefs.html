1. Descripción del Problema

La imagen principal del hero (hero-main-v4.jpg) se sirve actualmente sin comprimir con un tamaño de 2.4MB. Este recurso está bloqueando la ruta de renderizado principal, haciendo que el LCP (Renderizado de la Mayor Pintura de Contenido) se eleve a 3.2 segundos en conexiones móviles 4G.

2. Referencia Visual

image hero-main-v4.jpg (Estado Actual)

3. Especificación Técnica

Directivas

ACCIÓN: Convertir hero-main-v4.jpg al formato WebP.

TAMAÑO_OBJETIVO: < 200kb

DIMENSIONES: Mantener la resolución nativa de 1920x1080.

IMPLEMENTACIÓN: Añadir srcset para carga responsiva.

> Listo para ejecución

4. Justificación Estratégica

"Mejorar el LCP por debajo de 2.5 segundos recuperará una tasa de rebote estimada del 8% que se pierde actualmente durante la carga inicial. Esto se correlaciona directamente con una mayor conversión en el embudo principal."
